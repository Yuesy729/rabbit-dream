# 小兔造梦

SillyTavern 小剧场与长篇连载扩展，基于禾禾与麓克的 st-theater 4.4.8 定制版。原项目授权见 LICENSE.txt。

**安装**　使用酒馆「扩展 → 安装扩展」填入本项目的 GitHub 仓库地址。手动安装时，解压 ZIP，将含有 manifest.json 的目录放进当前用户的 extensions 目录，刷新酒馆。旧版用户可先导出备份，在扩展管理中停用原小剧场后再启用小兔造梦。两者共用原有配置与作品存储。

**打开**　点击输入框左侧的魔法棒，选择「小兔造梦」。写梦用于单篇创作，长梦管理连载与候选，书架整理已存作品，设置管理 API、外观与诊断。新配置默认使用亮色纯文字，已有模板选择沿用。

## 长梦

点「长梦」可以从已有的小剧场新建作品。在当前书名旁点「切换长梦」，可选其他作品或修改本卷设定。单篇写完后也可以点「加入长梦候选」，在目标卷里比较后再确认为正式章节。

源项目为 [st-theater](https://github.com/koichole213-ui/st-theater)。更多原有功能的说明见 [入门操作指南](GETTING_STARTED.md)。
